# Panel de Administración - Clínica Odontológica

Proyecto desarrollado para un cliente real (clínica odontológica). 
Este repositorio contiene el panel de administración web para la gestión de citas y pacientes.
Este proyecto esta dividido en Modulos.

## Mi rol en el proyecto
- Desarrollo del CRUD completo de pacientes (alta, edición, eliminación y consulta).
- Implementación de módulos de validación de formularios.
- Gestión de citas y control de usuarios.
- Colaboración en equipo utilizando Git y GitHub.

## Tecnologías utilizadas
 PHP, MySQL, HTML, CSS, JavaScript ...
